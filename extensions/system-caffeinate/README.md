# Caffeinate

Default-enabled top bar toggle for macOS `caffeinate`.

It adds a coffee button in the top right shelf. Clicking the button starts or stops a background `caffeinate -dimsu` process. The button glows while the process is active. You can also run **Caffeinate: Toggle Caffeinate** from the command palette or press `Cmd/Ctrl+Shift+C`.

The `caffeinate.autoStart` setting controls whether the extension starts `caffeinate` automatically when Neon Pilot starts. It is off by default and appears under Extension Settings as **Caffeinate**.
