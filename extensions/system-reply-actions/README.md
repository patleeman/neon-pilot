# Reply Actions

System Reply Actions owns transcript selection reply starters.

It contributes selection actions for the transcript context menu. Core provides the reusable selection/composer surface; this extension owns the product opinions like emoji draft starters.

## Settings

- `system-reply-actions.emojiPickerItems` — comma-separated reply starters for the transcript selection emoji picker. Each item is used as both the button label and the drafted reply text. Empty items are ignored; clear the value to remove the emoji starter buttons.
