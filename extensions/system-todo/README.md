# Todos

Conversation-scoped execution todos for Neon Pilot.

Todos are short-lived working plans shared by the user and agent. They are not projects, schedules, or durable knowledge. Goal mode owns continuation; this extension only tracks what remains.

## Tool

Use the `todo` tool to list, add, update, delete, or clear todos.

## UI

When enabled, the extension renders a compact composer shelf above the input. The shelf shows open todos first, keeps a small max height with scrolling, and lets the user mark items done/reopen, delete items, and clear completed items.
