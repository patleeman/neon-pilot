# Design Example Gallery

This gallery stores positive and negative visual anchors for Neon Pilot UI work. Use it alongside `docs/design/neon-pilot-taste.md` and `benchmarks/extension-quality/visual-rubric.md`.

Each example should include:

- screenshot or artifact path when available
- what works or fails
- what to do instead
- related rubric tags

Do not treat examples as one-off complaints. If an example captures a repeatable pattern, promote the rule into the taste doc or visual rubric.
