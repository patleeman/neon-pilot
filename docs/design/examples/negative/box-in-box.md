# Negative Anchor: Box-In-Box Layouts

Avoid nested cards, bordered sections, and floating panels as the default layout strategy.

## Fails Because

- Card stacks create visual noise and reduce IDE density.
- Borders become decoration instead of structural separation.
- The page starts to look like a dashboard template.
- Nested containers fight the host shell instead of integrating with it.

## Prefer Instead

- Flat surfaces with sparse, purposeful dividers.
- Rows, tables, trees, lists, inspectors, and split regions.
- Hierarchy from placement, alignment, type, and compact grouping.
