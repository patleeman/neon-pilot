# Negative Anchor: Title + Description Noise

Do not create a two-line label/description pattern everywhere.

## Fails Because

- Descriptions often restate labels instead of adding operational value.
- Repeated two-line items make dense surfaces harder to scan.
- Page hierarchy becomes prose-driven instead of structure-driven.
- The result feels generated and over-explained.

## Prefer Instead

- Let nav items, row names, section titles, and labels stand on their own.
- Add secondary text only for state, constraints, consequences, recovery, counts, source, or non-obvious behavior.
- Use compact metadata columns or inline status where possible.
