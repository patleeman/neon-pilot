# Loose Ends

Loose Ends is an experimental conversation-scoped right rail for preserving important context that would otherwise be lost: assumptions, non-obvious tradeoffs, surprises, nearby bugs or tech debt, follow-ups, risks, and validation limits.

It is intentionally not a work log. Ordinary implementation steps, changed files, commands, and test output belong in the transcript, not Loose Ends.

The extension is bundled but disabled by default. Enable it from Extension Manager, then turn it on per conversation from the right rail.
