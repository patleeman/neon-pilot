What It Is

Not another chat wrapper. A runtime your agent lives in.

Conversations, files, tools, skills, automations, and extension UI all live in one process. The agent holds context across sessions, kicks off durable work in the background, and picks up where it left off.

Core stays intentionally small. Every product behavior ships as an extension—so a useful workflow can become a reusable capability instead of a one-off chat.

Capabilities

The pieces agents actually need.

01

Persistent threads

Keep context, branches, run history, and follow-ups across sessions. The agent remembers what it was doing and why.

02

Skills & tools

Write repeatable workflows as skills the agent can invoke. Expose safe callable capabilities through the tool system.

03

Background runs

Kick off durable work, inspect logs, and resume the conversation when it matters. No more babysitting long tasks.

04

Extensions

Add pages, panels, commands, MCP servers, and custom workflows. Everything is a package—core never becomes a junk drawer.
