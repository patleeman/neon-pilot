How self-extension works

Ask for capabilities, not settings.

The unique loop is simple: request a feature in plain English, let the agent build the right product surface, validate it, and keep it available for future work.

Example request

PM “Add a command to summarize open PRs.”

Neon Pilot’s plan
  • Design command interface
  • Implement PR summarizer
  • Add tests and docs
  • Integrate command palette
Build & integrate
  • Created command
  • Updated palette
  • Tests passed
  • Docs written
