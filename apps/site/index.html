How it works

Most agent UIs forget everything between sessions. Neon Pilot wraps the Pi Coding Agent in a local runtime where context, tools, and workflows are durable.

1

Build a workflow

Talk to the agent. It reads files, runs commands, holds context, and works in the background.

2

Package it

Turn useful patterns into skills, tools, or extensions. The extension system is first-class.

3

It sticks

Future sessions discover the capability automatically. The agent gets sharper every time you use it.

Product demo

Neon Pilot 
> build me a browser tool

  reading   system-browser/README.md
  writing   extensions/system-browser/tool.json
  running   pnpm run check:extensions:quick
  commit    feat: add browser tool

✓ Browser tool installed.
✓ Reloaded agent context.
✓ New tool available in this session.

The agent reads extension docs, wires the manifest, validates, and checkpoints. The new tool appears without a restart.

The pieces agents need

  • Persistent threads — Context, branches, run history, and follow-ups survive across sessions.
  • Skills & tools — Write repeatable workflows as skills. Expose safe callable capabilities through the tool system.
  • Background runs — Kick off durable work, inspect logs, and resume when it matters.
  • Extensions — Add pages, panels, commands, MCP servers, and workflows as packages. Core stays small.
  • Knowledge base — Durable docs, skills, and instruction files synced to a git-backed vault.
