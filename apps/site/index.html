The idea

Build it. Package it. It sticks.

1

Build a workflow

Talk to the agent naturally. It inspects files, runs commands, holds context, and works in the background while you focus elsewhere.

2

Package it

When a pattern proves useful, turn it into a skill, tool, or extension. The extension system is first-class, not bolted on.

3

It sticks

Future sessions discover capabilities automatically. The agent gets sharper with every workflow you package.

What you see

The agent builds its own tooling.

When you ask Neon Pilot to add a capability, it reads the extension docs, wires up the manifest, validates, and checkpoints. The new tool appears in future sessions without a restart.

Read the extension docs
agent 
> build me a browser tool

  reading   system-browser/README.md
  writing  extensions/browser/tool.json
  running  pnpm run check:extensions:quick
  commit   feat: add browser tool

✓ Browser tool installed.
✓ Reloaded agent context.
✓ New tool available in this session.
