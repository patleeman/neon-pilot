Why it exists

Built for agents that improve their own workspace.

Persistent conversations

Threads, context, runs, and background work survive beyond a single chat turn.

Skills and tools

Capture repeatable workflows as reusable agent instructions and callable capabilities.

Async automation

Local-first extensions

Add pages, panels, commands, tools, MCP servers, and workflows without bloating core.

Self-extensible by design

Teach it once. Package it. Reuse it forever.

Neon Pilot is a small runtime with first-class extension boundaries. When a workflow graduates from a chat, it can become a skill, tool, automation, or UI surface future sessions can discover automatically.
