Self-extension lifecycle

Ask for a feature. Keep the capability.

Neon Pilot does not stop at answering. It can decide whether your request belongs as a command, tool, workflow, automation, knowledge surface, or extension — then add it to the product surface.

> add a command that summarizes open PRs

plan command + GitHub tool + tests + docs

write commands/pr_summary.ts

run pnpm run check:extensions:quick
