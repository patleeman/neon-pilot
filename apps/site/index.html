An AI workspace you can teach.

Neon Pilot is a local desktop app for running agents with memory, tools, background work, and extensions. When a workflow becomes useful, turn it into something the agent can reuse.

Download for macOS Source on GitHub

What It Is

A small runtime, not another chat wrapper.

Conversations, files, skills, tools, automations, and extension UI all live in one app. The agent can inspect the workspace, run jobs, save durable context, and come back later when work is ready.

Core stays small. Product behavior ships as extensions, so useful workflows can grow without turning the app into a junk drawer.
