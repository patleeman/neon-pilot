Neon Pilot

A desktop agent harness that gets sharper every time you use it.

It wraps the Pi Coding Agent with persistent conversations, local tools, background automations, and a first-class extension system. Teach it a workflow, package it, and future sessions pick it up automatically.

Download for macOS View on GitHub

What it is

Neon Pilot is a local Electron app. Conversations persist. Tools are callable. Extensions are first-class packages that add pages, panels, commands, MCP servers, and custom workflows. Core stays small — everything else lives in extensions.

The same agent that builds Neon Pilot also uses it. Skills, tools, and automations accumulate in the workspace over time.

The pieces agents actually need

  1. Persistent threads

    Context, branches, run history, and follow-ups survive across sessions. The agent remembers what it was doing and why.

  2. Skills & tools

    Write repeatable workflows as skills the agent can invoke. Expose safe callable capabilities through the tool system.

  3. Background runs

    Kick off durable work, inspect logs, and resume the conversation when it matters. No babysitting required.

  4. Extensions

    Add pages, panels, commands, MCP servers, and workflows. Everything is a package — core never becomes a junk drawer.
